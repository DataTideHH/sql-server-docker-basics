# SQL Examples

This folder contains small SQL Server example scripts for the local Docker-based learning environment.

## Files

| File | Purpose |
|---|---|
| `01_basic_checks.sql` | Check SQL Server version, current database and available databases |
| `02_training_queries.sql` | Example query patterns for inspecting tables and writing simple analysis queries |

## How to Use

1. Start the SQL Server container.
2. Connect with DataGrip.
3. Open one script at a time.
4. Select the correct SQL Server data source.
5. Run the statements block by block.

## Notes

The examples are intentionally simple.

They are meant for:

- learning SQL Server basics
- checking a local Docker-based SQL Server setup
- practicing DataGrip workflows
- preparing later Data/BI exercises

They are not production scripts.
